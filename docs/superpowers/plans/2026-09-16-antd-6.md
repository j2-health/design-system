# Ant Design 6 Implementation Plan

**Goal:** Prepare version 0.4.0 against Ant Design 6, preserving the library's
styling and Formik behavior.

**Architecture:** Replace the incompatible formik-antd peer with local Formik
bindings. Keep Formik as the source of truth for field values, validation,
submission, and reset. Adapt existing wrappers and CSS to Ant Design 6 rather
than introducing a second component library.

**Tech stack:** React 18/19, TypeScript, Formik 2, Ant Design ^6.6.3, icons 6,
Tailwind 3, Vitest, Storybook.

**Approved design:** Ant Design 6 only; release 0.4.0; replace formik-antd;
audit wrappers, tokens and CSS; verify tests, builds, packed consumer and
browser rendering.

## Constraints

- Generic presentational components and synthetic examples only.
- Preserve supported Formik field callbacks, nested paths, validation, touched
  state, select-all and clear-all.
- React remains ^18.3.1 || ^19.0.0; Tailwind remains ^3.4.14.
- No forced peer resolution or dependency overrides.

  tags mode and the v6 search configuration object.

### Compatibility note

Pagination still uses antd's supported-but-deprecated `selectComponentClass`
hook to apply the custom caret. Replacing it with an unconditional
`showSizeChanger` object forces visibility and breaks Table's inferred/filtered
totals and configured thresholds. Keep native visibility resolution until that
customization can be migrated without changing behavior. Development builds can
emit this deprecation warning.

Version 0.4.0 is prepared for release; publishing remains a maintainer action
through the documented release workflow.
